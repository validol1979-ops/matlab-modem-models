DSP-CIC-COMP MODEL CONTRACT (Python only; no RTL/HDL/vendor tools)
Read local source_context.json (Harris file pages490–491) and this contract. Book motivates droop compensation; all parameter/API/design choices below are project-derived. Existing copied cic_model/fir_fixed/fft_fixed are read-only and MUST NOT be edited.
Own common/python/cic_compensation.py and report.txt only, concise code. Dependencies NumPy and standard library; no vendor tools.
API:
1 cic_response(frequency, rate, stages=3, delay=1): normalized CIC DECIMATION magnitude at OUTPUT frequency f cycles/output sample. abs(sinc(M*f)/sinc(f/R))**N, stable DC=1 using np.sinc. f scalar->float, array->same-shape np.ndarray; finite f in[-.5,.5]. R1..32,N1..5,M1..2 integers, reject bool/noninteger. No raw(RM)^N gain factor. f=.5,M2 is zero within numerical epsilon.
2 design(rate,stages=3,delay=1,numtaps=31,passband=.16,stopband=.32,grid=512,pass_weight=10.0)->real np.ndarray h. Odd numtaps3..127, 0<passband<stopband<.5, grid>=numtaps and<=8192, finite positive pass_weight. Validate types/nonfinite. For linear-phase length2m+1 FIR, h[m]=1-2*sum(c_k), h[m+-k]=c_k. Sample grid passband0..pb and stopband sb...5, target inverse normalized CIC in passband and0 in stopband. Solve weighted linear least squares for c on A=2*(cos(2*pi*f*k)-1), y=desired-1, pass residual weight10 stop1. This imposes DC exactly, without a penalty term. Design is offline; reject inverse target singular/nonfinite. No per-profile tuning. Defaults/quality matrix below frozen.
3 quantize(taps)->list[(int_real,0)]. Validate nonempty odd finite real symmetric taps (tol1e-10). Q17 signed18 coefficients, nearest ties toward+infinity floor(h*131072+.5); maintain symmetry and adjust centre so sum(integer taps)==131072. If any coefficient after adjustment does not fit[-131072,131071], raise, do not silently clip. Export compatible with existing fir_fixed.filter/TAP_FRAC17. Do NOT use its banker's rounding quantizer silently.
4 metrics(taps,rate,stages=3,delay=1,passband=.16,stopband=.32,points=8193)->dict dc_gain,passband_ripple_db,passband_max_error_db,uncompensated_droop_db,fir_stopband_db,cascade_stopband_db. taps real finite odd, use direct DTFT on grid; log clamp1e-300; ripple peak-to-peak compensated magnitude. dc_gain=sum(taps), passband maxabsdB relativeunity; FIR stop and output-rate CIC*FIR stop separately.
5 cascade_fixed(samples,rate,stages,taps,delay=1)->list IQ int pairs. taps are already Q17 pairs returnedby quantize; require real, odd, nonempty signed18 coefficients. Call existing cic_model.decimate(samples,rate,stages=...,delay=...,normalize=True), then existing fir_fixed.filter (full FIR tail). Empty valid input->[]; validate params/taps even for empty. Input signed18 frame length multipleofR; accepted-sample model, no ready/valid/cycle claims. Do not implement duplicate FIR/CIC arithmetic.
Frozen acceptance matrix R4/10/32,N3/5,M1,L31/63,pb.16,sb.32,grid512,pass_weight10,metrics8193. BOTH float and quantized FIR: passband ripple<=.05dB, maxabs passband error<=.05dB, FIR stopband<=-50dB, DC gain1 (float tolerance1e-12, integer sum exact). ROOT prototype confirms feasible with this fixed LS method. Do not relax gates. Full rails may legitimately clip; characterize/compare exact existing FIR, never claim headroom at every input. Post-CIC FIR cannot undo aliases already folded into passband; do not claim it does. Source historical31tap fixture is not generic golden.


DSP-RATIONAL MODEL CONTRACT (Python only; no HDL/vendor tools)
Read local source_context.json and this contract. Own common/python/rational_model.py and report.txt only. NumPy/stdlib permitted. Do not edit main project or other agents. Write concise bounded-memory polyphase model, no explicit upsample/convolve in production. Tests/oracle supplied independently.
API classes RationalFloat(up,down,taps), RationalFixed(up,down,taps,input_width=18,coeff_frac=17,output_width=18). Positive coprime up=P/down=Q each1..32, reject bool/noninteger. taps nonempty real length1..2047. Float taps finite real (no complex/bool). Float samples finite complex/numeric (no bool), output complex. Fixed taps signed18 integer real coefficients Qcoeff_frac, samples exactly2 signed integers within input_width, coeff_frac0..30, input/output_width2..32, reject bool/nonintegers. Fixed output IQ pairs, exact full-width sum, one final (raw+2**(frac-1))>>frac (frac0 unchanged) and full signed output saturation; no intermediate wrap/clipping. Do not normalize or multiply taps byP silently. A unity-gain interpolation prototype normally has sum(h)=P, chosen by caller.
Sample convention: zero initial state, y[k]=sum_j h[(k*Q)%P+j*P] x[floor(k*Q/P)-j], first output k0 at high-rate time0. Class.push(sample)->list outputs causally available after accepted input; at N inputs emit precisely ceil(N*P/Q) outputs total, equivalent to filtering a zero-stuffed array of length N*P and taking [0::Q], truncated to that array length. Keep only at most ceil(len(taps)/P) original samples (bounded history) and phase counters. Q>P may skip MORE THAN1 input index between outputs; preserve every needed input. Phase sequence P5/Q3:0,3,1,4,2.
Class.flush(tail=True)->remaining outputs and CLOSE frame. tail=True emits through full convolution length N*P+len(h)-1 (output count ceil(that/Q)); note this deliberately includes final P-1 inserted zeros. tail=False finalizes at ceil(N*P/Q) outputs with no more tail. Empty frame returns[]; repeatflush idempotent[], invalid tail must reject without state mutation even after close. push after close raises until reset/configure. Empty input has no filter tail. Minimal-support scipy.upfirdn convention is shorter by final P-1 inserted zeros; DO NOT compare lengths without padding/cropping.
Class.reset()->None clears history/counts/closed but keeps config. Class.configure(up,down,taps)->None allowed only before first sample or after flush; validates all before changing anything, resetsstate; same ratio also resets. Bad sample/config/flush argument must leave state unchanged. New frame needs reset or configure, no implicit TLAST; do not claim cycle or backpressure modeling.
Public read-only properties phase=(next_output_index*Q)%P and input_index=floor(next_output_index*Q/P) expose NEXT output schedule. P/Q configure between frames only. Properties up/down maybepublic/read-only; keep input_width etc fixed on configure.
Batch resample_float(samples,up,down,taps,tail=True) and resample_fixed(samples,up,down,taps,tail=True,**width_kwargs) fresh class, pushes then flush, return outputs; validate options even for empty input.
Function accumulator_width(taps,up,input_width=18)->minimum signed width for ANY polyphase dot product over full signed input rails. For each branch sum min/max(c*x) exactly by coefficient sign, then compute minimal w s.t. -2**(w-1)<=lo and hi<=2**(w-1)-1. Real taps fixed signed18; positive up1..32. No floats/log rounding; no Numpy int overflow. This is a proven format bound, not actual wrapped arithmetic.
Matrix at least ratios(5,3),(3,5),(12,5),(1,2),(2,1),(1,1),(2,7),(1,32),(32,1); h lengths including1 (<P),P-1,P+1,17,63. Empty/singleton/shortframes, impulse/DC/tone/random, runtime reset/configure, invalid atomicity, fullrails/clipping. Explicit upsample+convolve oracle belongs ONLY in independent tests/reference.
