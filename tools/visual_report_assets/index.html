MSK agrees with the original waveform.

02
A FINDING THAT A PASS LABEL WOULD HIDE
QPSK has a constant label rotation.
The original error counter reports 100% symbol errors. After the archived 13-symbol delay, the received labels are shifted by three modulo four. A phase hypothesis chosen earlier in the capture gives zero errors on 5,455 held-out symbols after diagnostic correction.
The correction is shown for diagnosis. It has not been added to the original receiver.
The raw result and the corrected diagnostic are shown separately.Open SVG ↗
