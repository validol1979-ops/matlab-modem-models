# PFB, STFT, OFDM и OM-LSA: независимая точность

`python3 tools/spectral_precision.py` измеряет 46 случаев и проверяет 290 условий; 12 тестов проверяют масштаб, индексы, границы, независимость и отказы. Используются общие квантованные входы, загруженные коэффициенты и отдельные идеальные коэффициенты. Float эталоны не получают fixed промежуточные состояния.

| Тракт | Масштаб и границы | Наблюдения |
| --- | --- | --- |
| PFB | Причинные окна на end=0,D,…; FFT/M; точная фазовая перестановка | Обычный SQNR не ниже 59.33 dB |
| STFT | FFT/N; окна sqrt-Hann; только полные окна, без дополнения хвоста | Импульс у края при N=256: 28.63 dB; край не исключён из полного измерения |
| OFDM | Полный fixed TX → один AWGN → одна Q15 квантовка → независимые RX; CP удаляется явно | Разреженный RX при N=1024: 31.99 dB; дополнительная ошибка коэффициентов показана отдельно |
| OM-LSA | Независимые шумовые состояния, E1, gain; reflect padding и crop по физическим индексам | SQNR 68.00 dB для шума и 66.22 dB для stress |

STFT synthesis при общих fixed spectra — локальная проверка. Полный roundtrip использует независимый float analysis; он измеряется отдельно. Для N=256 tone full/interior SQNR равен 47.33/89.04 dB на заранее заданном интервале [192,960). Для краевого импульса энергия в этом интервале нулевая: высокий interior SQNR не заявляется.

Бюджет 45 dB выполняют 29 случаев, не выполняют 17. Среди последних есть clipping, реальные шумовые потери OFDM относительно исходных символов и два упомянутых слабых случая. PASS означает полноту и согласованность измерения и выполнение объявленных арифметических границ для конкретных сигналов; он не означает, что все случаи проходят бюджет качества. Границы не являются универсальным доказательством точности на всех входах.

Это Python измерение, без нового RTL режима, подгонки gain/phase, обещания SER или принятия новой разрядности. Эти задачи остаются в TODO.
