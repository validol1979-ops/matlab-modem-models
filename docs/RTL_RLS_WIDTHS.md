# Точные ширины скалярных произведений RLS

19 октября 2026 продолжен подбор внутренних разрядностей RLS. В `rtl/common/rls_filter.sv` добавлены default параметры `PRED_WIDTH=53+LOG2N`, `DOT_WIDTH=63+LOG2N`, `Q_WIDTH=67+LOG2N`. Они задают соответственно два регистра предсказания, общую комбинационную сумму предсказания/строки матрицы и сумму hᴴu. Прежние 64/128/128 доступны для контроля. Порядок прежних позиционных параметров сохранён; недостаточные ширины и значения выше 128 отклоняются с `[PARAMETER]`.

При N=1/2/4/8/16 используются 53…57, 63…67 и 67…71 бит. Существующее переключение предсказания/матричного произведения и число тактов сохранены; общий тракт рассчитан на более широкий матричный операнд. Другие 128-битные вычисления обновления весов/ковариации, ширины состояний и алгоритм округления/насыщения на этом этапе не менялись. Fixed-модель не менялась.

Для двух комплексных произведений signed W×signed18 и N=2^LOG2N точные границы суммы имеют вид:

```
plus_min  = N * (-2^(W+17) + 2^18)
plus_max  = N * 2^(W+17)
minus_min = -N * (2^(W+17) - 2^17)
minus_max =  N * (2^(W+17) - 2^17)
common_signed_width = W + 19 + LOG2N
```

W=34 для весов, 44 для P и 48 для u. В матричном произведении компоненты с плюсом и минусом меняются местами; общая ширина та же. Добавки округления 2^29 для предсказания и 2^14 для U/Q помещаются в этих ширинах. Шестнадцать углов каждой пары комплексных операндов проверены независимо; повторение угла на всех активных отводах достигает границы общей суммы для произвольных кодов операндов. В частности, при N=16 матричная сумма достигает 2^65, hᴴu — 2^69: промежуточный longint64 был бы недостаточен.

Знаменатель оставлен signed51: после sat50 величина q лежит в `[-2^49,2^49−1]`, а положительный unsigned30 LAM — в `[1,2^30−1]`. Поэтому D находится в `[-2^49+1,2^49+2^30−2]`. Верхняя граница не помещается в signed50. Нормированный reciprocal и его задержка не менялись.

Проверка состоит из двух разных областей. На полных траекториях адаптации монитор строит историю из исходных файлов, сверяет принятые поля и вычисляет 128-битные теневые суммы по **фактическим ограниченным w/P/u состояниям DUT**. Он проверяет сырые предсказания, регистры предсказаний, каждую строку P·h, hᴴu и D после округления/sat50. Состояния w/P/u не объявляются независимой копией модели. Независимые битоточные scoreboard выходов/весов и девять групп насыщений продолжают проверять функциональное поведение.

Отдельный `rls_dot_bounds_tb.sv` без фронтов такта задаёт произвольные коды внутренних операндов через тестовый force и проверяет реальную комбинационную арифметику DUT. Перебираются 16 углов для 34/44/48-битных операндов, все строки, N=1…16, новые/старые размеры и обе полярности параметра сброса. **Достижимость этих углов из reset адаптации не утверждается.** Это проверка вместимости арифметики, дополняющая, а не заменяющая проверку траекторий.

Первый запуск направленного теста остановился при загрузке: процедурные записи в регистры always_ff нарушали правило единственного владельца. Они заменены на force с постоянными индексами generate; тактовых фронтов в этом тесте нет. Исходный журнал сохранён, финальная короткая серия повторена на окончательном снимке: старый RTL 16 прогонов, новый 8 траекторий и 5 направленных конфигураций.

Основная матрица: восемь наборов (N=1…16, неполная история 3/4, weight34 и p44 stress) × пять раскладок × две полярности × пять сценариев = 400 обычных прогонов. Раскладки включают новые/прежние размеры и возврат каждого отдельного параметра. Отдельно проверяются 96 отказов параметров, 20 направленных прогонов и 12 отрицательных контролей `[PREDICT]`, `[REGISTER]`, `[MATRIX]`, `[QUADRATIC]`, `[DENOMINATOR]`, `[ARITHMETIC]`. Две полярности выполняются параллельно в разных библиотеках. Сырые пики и парные такты должны совпасть при смене ширин; паузы и сбросы не должны менять проверяемую траекторию.
