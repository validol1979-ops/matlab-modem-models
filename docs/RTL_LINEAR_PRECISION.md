# MMSE, beamformer и Alamouti: независимая точность

`tools/linear_precision.py` проверяет 14 обычных конфигураций, четыре случая выходного clipping и шесть конфигурационных отказов. H/steering/channel/observations округляются один раз в signed18 Q15, λ — unsigned34 Q30. Независимые NumPy solve/linear formulas получают только эти общие слова и параметры.

MMSE2/3 охватывают комплексный ZF, регуляризованный комплексный канал, регуляризованную rank-deficient матрицу и tiny identity. Beamformer использует восемь steering components, слабый комплексный steering и один tiny coefficient. Alamouti проверяет комплексную/ортогональную/tiny пару каналов и документированное сопряжение второго наблюдения.

Обычные случаи не имеют input/output clamps. Конечный output SQNR — 72.47–94.29 дБ; RMS расхождения — 1.21–1.32×10⁻⁵ нормализованных единиц сигнала (`integer/32768`). Максимальная относительная RMS ошибка коэффициентов — 6.75×10⁻⁸. Четыре tiny случая совпадают точно.

MMSE веса сравниваются в нативном Q24: signed48 для n2, signed64 для n3. Для beam/Alamouti fixed effective coefficients восстанавливаются из реально используемого R/Z encoding только на стороне измеряемого тракта. Floating reference не получает эти значения: коэффициенты вычисляются независимо из общих Q15 параметров. Интерфейс coefficient dump у beam/Alamouti не заявляется.

Четыре выходных stress дали MMSE2/MMSE3/beam/Alamouti 4/6/4/2 события ограничения. Отчёт разделяет искажение относительно неограниченного эталона и совпадение с независимо ограниченным эталоном. `quality_accepted=false` для stress.

Вырожденная MMSE без регуляризации, переполнение MMSE coefficient и нулевая энергия beam/Alamouti отвергаются. Переполнение подтверждается точным integer determinant/adjugate certificate на unimodular H; неустойчивый floating Gram не используется как доказательство сингулярности. Отказы не выдают числовых результатов и не признаются качественной обработкой.

Проверки требуют полного набора конфигураций, точных hash/shape/span, независимо вычисленного числа операций и согласованности RMS/MSE/SQNR. Пропущенные случаи, лишние стадии, неверные spans, NaN и подмена классификации отвергаются. Это исследование моделей; SER, новые RTL качества и смена рабочих разрядностей не заявляются.
