# Активные индексы FIR, FFT и OQPSK

Продолжение проверок FIFO и индексов из [DSP checkpoint](RTL_DSP_SATURATION.md). Новые наблюдатели находятся только в тестбенчах. При их добавлении ядра FIR, FFT и OQPSK были сохранены; затем в FIR исправлен обмен конфигурацией без изменения арифметики — [отдельные протокольные проверки](RTL_CONFIGURATION_PROTOCOL.md). Ожидаемые переходы выводятся из действительных принятых/выданных операций, с учётом одновременных действий и сброса.

| Блок | Проверенные активные структуры | Нормальные симуляции |
| --- | --- | ---: |
| FIR | Шаг/индекс отвода, lifetime кольца, адреса и маски банков, FIFO/резервирование/указатели | 80 |
| FFT | Commutator counters, twiddle ROM, динамический delay RAM, банки reorder, FIFO/inflight, valid warm-up/flush | 70 |
| OQPSK | TX buffer, capture RAM, acquisition lag/переходы, training indices, reader/symbol reservations, Costas/error ring и маски cubic | 20 |

FIR отдельно подтверждает одновременные push/pop. У FFT используется существующая линия validity tags ограничителей; статические register delays не выдаются за динамический RAM. Для N = 4/32 счётчик delay RAM равен нулю, для N = 64/1024 он обязателен и ненулевой. Отрицательная инъекция неверного twiddle address проверяется на всех семи конфигурациях и обеих полярностях сброса.

OQPSK допускает нули за пределами captured frame. Новый `tailcut` план обрезает вход RX до 2048 отсчётов при N = 256 и задержке 7.25; после хвоста FIR capture содержит 2080 отсчётов. Реально проверены восемь внешних нулевых taps на обеих полярностях. Повреждение настоящего DUT tap через `+INJECT_ZERO_DATA` должно вызвать `[BOUNDS]`. Payload SER этого стрессового случая измерен как 2/64; условие нулевого SER не вводится. Максимальный план дополнительно упражняет tail RAM; проверенные пики — семь reader requests и четыре символа в полёте.

Все наблюдатели требуют положительных счётчиков упражнённых состояний. Выбранные незаконные адреса и неверная подстановка нуля должны дать Fatal с нужной категорией, ненулевой код Questa и отсутствие итогового PASS. В `.do` используются `onfinish stop`, `onerror/onbreak → 13`; файл передаётся по имени из рабочего каталога, поскольку абсолютный путь с кириллицей воспроизведённо ломает vish в установленной Questa.

Команды: `python3 tools/run_fir.py --suite all`, `python3 tools/run_fft.py --suite all`, `python3 tools/run_oqpsk.py --suite all`. Существующие файлы векторов сохранены; `tailcut` добавлен отдельным планом. Проверки охватывают перечисленные структуры; внутренние CORDIC/divider OQPSK проверены в продолжении ниже. FIR расширен в продолжении ниже.

Продолжение: вложенный `bpsk_fir` в OQPSK теперь проверяет живые регистровые history cells, принадлежность кадру и восемь enabled-clock valid/last stages. Динамических RAM/ROM адресов в этом FIR нет. Паузы CE реально упражнены на TX; RX CE постоянно равен единице. Отрицательные контроли активного индекса и paused-valid отвергаются. Вложенные CORDIC/divider описаны в продолжении ниже.

Продолжение CORDIC/divider и нулевого fraction denominator — [RTL_OQPSK_NESTED_BOUNDS.md](RTL_OQPSK_NESTED_BOUNDS.md): 21 CE-ступень, latched request и 64 iteration indices, round/sign, active known data и реальный bypass.
