# SER по реально принятым меткам RTL

`bpsk_rx_tb.sv` уже сравнивал выход DUT с битоточной моделью и считал суммарные ошибки против исходных переданных меток. Теперь результат сохраняется явно по каждому кадру в `run_bpsk.py`: профиль, сценарий, полярность сброса, ошибки, число payload symbols и SER.

Числовое табло сравнивает принятую при `m_valid && m_ready` метку с колонкой 7 `rx_trace.txt` — решением fixed-модели. Отдельный счётчик SER сравнивает эту же реальную метку DUT с колонкой 9 — исходной переданной меткой. Первые 192 символа обучения исключены. Фазовая/квадрантная поправка по payload truth не применяется.

По окончании каждого кадра тестбенч печатает `RTL PAYLOAD SER frame=… errors=… symbols=…`. Runner требует все маркеры по порядку, точный знаменатель `SYMBOLS−192`, допустимое число ошибок и совпадение ошибок с соответствующим кадром исходного отчёта. Также обязателен успешный числовой прогон. Пропуск, дубликат, неверный знаменатель/числитель и Fatal отвергаются.

Минимальные кадры по 192 символа содержат только обучение: `defined=false`, `ser=null`, число payload symbols равно нулю. Они проверяют обмен и числовые результаты, но не характеризуют SER. Сброс посреди предварительного кадра подавляет его маркеры и очищает все счётчики перед повторным полным прогоном.

Полный набор включает 170 записей сценариев, 1212 кадров и 789504 payload symbols, включая повторения с остановками и сбросами. У 28 записей знаменатель нулевой. На смешанных каналах стандартного BPSK stream получено 255 ошибок из 6912 payload symbols при каждой полярности; это агрегат разных каналов, не универсальная оценка при одном SNR.

Четыре семейства отрицательных контролей — общие BPSK блоки, MRC, BPSK RX и RX остальных профилей — теперь требуют настоящего ненулевого кода Questa, UVM `[NUMERIC]`, ненулевого итогового счётчика Fatal и отсутствия итогового PASS. Выполняются 32 таких контроля; Tcl передаётся по basename с лимитом 90 секунд на контроль. Отдельные Python-тесты проверяют отказ повреждённых SER-маркеров.

Это SystemVerilog тестбенч с UVM package/macros. Полное UVM окружение с component/sequence/monitor для модема остаётся отдельным пунктом TODO. Измерение SER не заменяет его и не добавляет нового стрессового канала. Все прежние 242 текстовых файла векторов сохранены.
