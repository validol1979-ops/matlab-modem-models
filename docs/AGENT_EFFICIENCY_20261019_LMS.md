# Luna: узкая проверка энергии LMS/NLMS

По просьбе пользователя задачи назначаются с учётом подтверждённого уровня агента. Для этого этапа Codex 6 Luna (`gpt-6-luna`, агент `luna_lms_energy`) получил read-only арифметическую проверку: найти максимумы энергии signed18 комплексной истории и суммы с unsigned34 EPS для N=1/2/4/8/16. Архитектура, изменение RTL, тестовые мониторы и итоговая приёмка оставались у основного агента.

Luna верно получил ширины 36/37/38/39/40, включая power_max=549755813888 и total_max=566935683071 при N=16. Проверка модели подтвердила допустимый EPS от 512 до 2^34−1. В дополнительной ограниченной задаче агент сравнил все 512 значений reciprocal: `round(2^19/m)` совпадает с `(2^19+m//2)//m` для используемых m. Основной агент независимо проверил границы и воспроизвёл реальный числовой отказ прежнего RTL.

Первый отчёт поступил в 12:51:13 UTC, дополнительный — в 12:56:06 UTC. По отчёту агента использовано соответственно три и один вызов инструмента. Это времена получения результатов, а не измеренная длительность работы. Достоверного отдельного измерения стоимости/токенов нет. Ошибочных арифметических выводов в этой задаче не обнаружено; оценка не распространяется на самостоятельную интеграцию.

Исторические результаты Pi/OpenCode/Kilo уже сведены в [первом сравнении](AGENT_EFFICIENCY_20261019.md): по семь запусков, завершились 5/5/1, медианы времени 210/262.1/146 секунд для завершившихся запусков. Задачи и лимиты различались; эти числа не дают честного рейтинга качества или скорости относительно текущей узкой задачи Luna. Новый запуск этих трёх оболочек на одинаковом задании здесь не проводился.

Практический вывод этого этапа: Luna успешно выполнил ограниченный расчёт с однозначным проверяемым ответом.
