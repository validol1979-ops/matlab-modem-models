# Точность полных LMS/NLMS/RLS петель

`tools/adaptive_precision.py` сравнивает production fixed recursions с независимыми вещественными петлями `research_core.run`. Обе получают одни и те же input/desired слова, однажды округлённые в signed18 Q15. Floating модель самостоятельно обновляет историю, веса и covariance; состояние fixed модели ей не передаётся.

Три сигнала с комплексным FIR plant дают девять обычных сравнений: тихий и шумовой тракт с тремя отводами, шумовой тракт с восемью. Длина — 1200, steady interval — 400…1199, early interval — первые 64 отсчёта. Complex input RMS равен 0.7; RMS добавленного комплексного шума — 0/0.01/0.03. Исходные коэффициенты plant используются для генерации desired; оценённые веса не подгоняются по truth, фазе или перестановке.

| Алгоритм | Prediction SQNR по трём steady случаям | Наибольшее RMS расхождение prediction |
| --- | ---: | ---: |
| LMS | 85.25–91.44 дБ | 1.33×10⁻⁵ |
| NLMS | 79.49–89.46 дБ | 2.58×10⁻⁵ |
| RLS | 85.74–91.48 дБ | 1.27×10⁻⁵ |

RMS выражено в нормализованных единицах сигнала: integer word /32768. Ошибка экспортированных Q15 весов — 0.87–1.75×10⁻⁵ единиц коэффициента; dump rounding включён. Внутренние веса signed34 Q30 не выдаются за экспортированный результат.

Обычные случаи имеют нулевые clamp events. Наибольшее отношение steady MSE к early MSE — 0.2638. Приёмка требует prediction SQNR ≥40 дБ, расхождение prediction/error RMS ≤0.001, exported-weight RMS ≤0.003, сходимость и согласованность MSE с floating с отдельным полом ошибки в два LSB. В тихом случае энергия остатка мала, error SQNR равен примерно 1.76–1.93 дБ; для этого остатка применяется абсолютная RMS ошибка, а не порог SQNR.

## Объявленные различия

- LMS/NLMS получают одинаковые сконфигурированные MU Q17 и EPS Q30; NLMS fixed использует reciprocal ROM по десяти старшим битам мантиссы.
- RLS floating начинает с того же P0 Q28 и λ Q28; fixed INVL отдельно округлён в Q30.
- Fixed RLS обновляет верхний треугольник P, зеркалирует комплексное сопряжение и обнуляет мнимую диагональ. Floating обновляет собственную полную комплексную матрицу.
- Fixed prediction/error ограничены signed18 Q15, обновляемые веса — signed34 Q30, экспорт — signed18 Q15.

Три отдельных clipping stress дают LMS/NLMS/RLS 2/2/10 событий. `quality_accepted=false`: ошибка включает clipping, не только квантование. Потеря положительности RLS denominator классифицируется как диагностический отказ; такой случай не признаётся успешным измерением качества.

Число операций выводится независимо из samples/taps и алгоритма. Проверяются полные диапазоны измерений, равенство исходных слов для алгоритмов, сохранение результата при включённом наблюдателе и отсутствие лишних стадий. Подмена метаданных, пустая/неполная выборка и ошибочная классификация отвергаются. Это исследование моделей; новые RTL сигналы для приёмки качества и полная область устойчивости остаются дальнейшей работой.
