# Полная шкала выходов и перегрузка RTL

Продолжение контрольной точки 2026-10-08. Вчерашние изменения генераторов проверены,
планы дополнены для OM-LSA и OQPSK RX. PFB, FSK TX и OQPSK TX имеют выходные границы
ниже полной шкалы; для них добавлены проверки этих границ. RTL и целочисленные модели
на этом этапе не менялись. Синтез Quartus/Vivado остаётся на паузе.

Работу делили с Qwen через pi и `opencode/mimo-v2.6-flash-free` через OpenCode.
Агенты работали в копиях `build/rtl/continuation_20261009/{pi,opencode}/`.
Результаты проверены координатором; в расчёте PFB дополнительно учтено квантование
комплексных коэффициентов FFT. Исследование OpenCode использовано для компактных
векторов OM-LSA и OQPSK и расчёта границ loopback.

## Контракт проверки

Для 18-битных выходов проверяются реальные границы `+131071` и `-131072`, для
апостериорных значений LDPC — `+32767` и `-32768`. У FFT отрицательная граница
симметрична положительной по контракту ядра. Дополнительные транзакции используют
детерминированные входы и следуют после всех прежних случайных транзакций.

Сверка с генераторами коммита `c1ddfb0` прошла для **74 конфигураций и 325 файлов**:
конфигурации неизменны, прежние строки каждого потока сохранены побайтно. Меняются
только заголовки числа строк и добавляются хвостовые транзакции. 153 файла полностью
неизменны. Аудитор, исходная копия изменений, параметры запусков, SHA-256 префиксов
и журналы сохранены в `build/rtl/continuation_20261009/`.

Счётчик `stream_cover` отмечает значение на полной шкале. Это само по себе не
доказывает срабатывание ветви ограничения: FIR с единичным усилением и Kalman
могут достичь границы, сохраняя математически ограниченный выход. У FIR поле
`output_clipping` отдельно показывает, выходит ли точная граница до ограничения
за допустимый диапазон. Внутренние ограничения требуют отдельных счётчиков.

| Costas | Короткий разгон петли и полные комплексные углы | Обе границы при ненулевых коэффициентах |

| Gardner | Ступенчатый вход полной шкалы с допустимым хвостом | Обе границы |

| LDPC posterior | Действительное ненулевое кодовое слово, LLR ±32767 | Обе 16-битные границы во всех четырёх режимах |
| MMSE | Экстремумы по всем 16 углам входного прямоугольника | Обе границы, кроме `strong` |
| MMSE strong | Граница 66219 на коэффициентах текущего seed | Полная шкала недостижима на этой конфигурации |
| OM-LSA | Знакопеременный префикс оценки шума, затем прямоугольная волна периода 16 | Обе границы; спектральные маски вызывают выбросы ISTFT |
| OQPSK RX | Дополнительный сырой кадр полной шкалы со сменой знака | Обе границы на длинах 192/768/2048 |
| OQPSK TX / loopback RX | Границы 12154 / 68229 по реальным таблицам FIR, cubic и cosine | Полная шкала недостижима; loopback сохраняет настоящий TX→RX |

OQPSK stress-кадр проверяет арифметику и протокол на допустимом входе. Его значения
не являются корректной переданной преамбулой; количество ошибок полезных символов
записано, но не используется для заявления о качестве приёма. Предшествующие
канальные и loopback-кадры остаются прежними.

Граница PFB считается в целых числах: сначала ограничение каждой полифазной
компоненты через сумму модулей коэффициентов, затем потолок комплексного модуля.
Каждая ступень FFT увеличивает эту границу не более чем в `1+1/65536` раза плюс
один на округление. Это учитывает отклонение модуля Q16 twiddle от единицы.

## Команды

```bash
python3 tools/run_streaming_rtl.py --suite all
python3 tools/run_tests.py --suite all
python3 tools/coverage_report.py --require-mode-bins
```

`run_streaming_rtl.py` объединяет 15 наборов FFT/DSP/OQPSK без синтеза. Можно выбрать
наборы через `--blocks omlsa oqpsk` или этап через `--suite python|lint|hdl|all`.
Каждый дочерний результат проверяется через `require_pass`; результат должен быть
создан после начала текущего общего запуска. Общая запись PASS требует успеха
всех выбранных наборов и неизменности исходников и артефактов. Проверены отказы при
`python -O`, ненулевом коде дочернего процесса и подстановке прежней записи PASS.

## Итоговая приёмка

2026-10-09 на одном снимке исходников:

- Все **15 потоковых наборов** `--suite all` прошли Python, строгий Verilator lint
  и Questa с обеими полярностями сброса, паузами и сбросами внутри транзакций.
  Отрицательные числовые контроли обнаружены. Общий прогон занял около 355 секунд.
- Полная переносимая регрессия прошла за 133.24 секунды: **308 Python-тестов**,
  24 модема в Octave, 96 кадров UVM с 445328 комплексными сравнениями;
  40 типизированных сценариев, 80 UVM-транзакций с 32084 сравнениями.
- `coverage_report.py --require-mode-bins` прошёл. У 19 числовых потоков есть обе
  границы полной шкалы; четыре оставшихся числовых выхода имеют доказанные границы
  ниже полной шкалы. [Таблица покрытия](RTL_COVERAGE.md) обновлена.
- `require_pass` подтвердил свежесть общей переносимой регрессии, общей потоковой
  регрессии и всех 15 дочерних результатов, включая хеши журналов и векторов.

Сводная запись и свидетельства сверки префиксов —
[rtl_overload_results.json](rtl_overload_results.json). Следующий этап: счётчики
внутренних ограничений на тех же векторах, затем отдельные сценарии захвата и

решением пользователя.
