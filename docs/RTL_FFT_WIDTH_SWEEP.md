# Выбор guard bits FFT на заданном диапазоне

`python3 tools/fft_width_sweep.py --verify-rtl` исследует существующий параметр WIDTH при неизменных signed18 Q15 входах и Q16 twiddle. Меняются целочисленный запас и симметричный ограничитель каждой ступени. Дробная точность и разрядность twiddle остаются прежними.

Проверяются WIDTH 19/20/21/22/24 и N 64/256/1024: 75 измерений. Каждая ширина получает одни и те же integer inputs; независимый эталон NumPy использует `FFT/N` или `N*IFFT`. Номинальный диапазон состоит из forward random, tone, corner и inverse random с компонентами от −2048 до 2048. Отдельный inverse stress содержит одинаковые максимальные допустимые комплексные компоненты во всех bins.

Бюджет эксперимента: SQNR ≥50 дБ, RMS EVM ≤0.003 и отсутствие clipping в номинальных случаях. Минимальный номинальный SQNR равен 70.72 дБ, максимальный EVM — 0.02911%. Все исследованные ширины проходят этот диапазон; минимальный кандидат — 19. WIDTH20 сверяется бит в бит с текущим production default.

| WIDTH | Clipping events на coherent inverse stress |
| --- | ---: |
| 19 | 2010 |
| 20 | 1002 |
| 21 | 498 |
| 22 | 246 |
| 24 | 57 |

Ни одна исследованная ширина не сохраняет полный stress без clipping. Кандидат относится к объявленному конечному номинальному диапазону; default RTL не изменён и новая рабочая ширина не принята. Ресурсы и физический тайминг не измерялись.

## Проверка самого RTL

Параметры WIDTH19/20 проходят те же пять сигналов при трёх размерах, обеих полярностях сброса и режимах stream/stalled/midreset/outreset: 48 прогонов. Проверяются каждый числовой выход, реальные операции/события ограничителей и активные индексы. Отчёт требует полный уникальный набор комбинаций, `5*N` выходов и пять кадров, а также положительные признаки каждой проверки. Пропуск, дубликат, неверный счётчик или ложный признак проверки отвергается. Без `--verify-rtl` отчёт явно остаётся исследованием модели.

## Исправление входного контракта модели

Раньше `fft_fixed` принимал +131072 при signed18 и молча преобразовывал дробные компоненты через `int`. Оба случая не соответствуют входным портам. Public forward/inverse теперь требуют ровно две целочисленные компоненты в диапазоне −131072…131071; NumPy integer pairs поддерживаются.

Конъюгация законной мнимой компоненты −131072 даёт внутренние +131072 и сохраняется без усечения. Этот диапазон разрешён только внутренней конъюгированной мнимой оси. Четыре таких входа дают один положительный pre-clamp event внутри inverse и действительный выход −524287. Прежние реальные RTL-векторы воспроизведены без изменения: 230 кадров и 24296 отсчётов.
