# Потоковые MSK и GMSK

RTL для `msk_modulator_2008_06_22` (`GMSK=0`) и `gmsk_coherent_demodulation_2010_10_03` (`GMSK=1`) лежит в `rtl/modems/msk_modulator_2008_06_22/`: передатчик `cpm_tx`, приёмник `cpm_rx`, общий модулятор `cpm_modulator`, буфер отсчётов `cpm_samples` и когерентный тракт GMSK `cpm_coherent`. MSK принимается частотным дискриминатором, GMSK — когерентно (раздел ниже). Из пилота взяты таблица cos, кубический интерполятор, CORDIC (`bpsk_cordic`) и делитель (`bpsk_divide`). Целочисленный эталон — `common/python/cpm_fixed.py`, тесты — `tests/test_cpm_fixed.py`, прогон RTL — `python3 tools/run_cpm.py --suite all`.

## Передатчик

| Узел | Формат |
| --- | --- |
| Вход | бит на символ (`s_valid/s_bit/s_last`), 8 отсчётов на бит |
| Частота | MSK: f = ±2¹⁶; GMSK: последовательность ±1 через гауссов FIR (BT 0.3, 33 отвода Q16, сумма ровно 2¹⁶, крайние отводы нулевые) — пары симметричных отводов умножаются на −2…2 сдвигом в логике |
| Фаза | 32 бита, шаг f·2¹¹ за отсчёт (четверть оборота за символ), с начала кадра от 0 |
| Выход | cos/sin из таблицы пилота (4096 × Q17), округление до Q15; длина кадра 8N (MSK) или 8N + 32 (GMSK, хвост свёртки) |

Латентность модулятора — 8 тактов, II = 1. Выходной буфер на два отсчёта держит `m_ready` вне разрешения тактов, как в `bpsk_tx`. С вещественным `modem_core.transmit` MSK совпадает с точностью до 2·10⁻⁵, GMSK — до 1.5·10⁻³ (12 бит фазы в таблице).

## Приёмник

Вещественный `receive_cpm` перебирает 65 задержек с шагом 1/4 и подгоняет фазу по всей преамбуле. Для потока это слишком долго: обработка идёт по одному отсчёту на отсчёт входа, и захват должен уложиться в длительность кадра. Целочисленный приёмник находит задержку и частоту иначе — примерно за 2.2 тыс. тактов, когда в буфере 1088 отсчётов кадра:

1. **Проход 1** (1042 отсчёта в целых позициях): приращения дискриминатора inc[m] = angle(x_m·conj(x_{m−1})) коррелируются с опорной частотой преамбулы на 18 сдвигах (−1…16) одновременно: corr[j] += round(inc[m], 16)·w[m+1−j]. Опору строит свой `cpm_modulator` из битов преамбулы: для MSK вес — знак f, для GMSK — round(f, 8).
2. **Пик**: первый максимум. Дробная часть берётся из треугольника для MSK (корреляция прямоугольных частотных импульсов) или из параболы для GMSK (значения >> 5, чтобы знаменатель уместился в 32 бита), ограничивается ±1/2.
3. **Проход 2** (1024 отсчёта при найденной задержке): x·conj(r) в 8 блоках по 128. Фазы блоков (CORDIC) разворачиваются, наклон по МНК: slope = divide(6·Σ(2j−7)·p_j, 64512).

Данные MSK: позиции n + задержка + 1/2 (приращение отсчёта n покрывает n−1…n, окно символа центрируется на полотсчёта позже; вещественная подгонка при низком ОСШ сама приходит к такому сдвигу), приращения wrap(angle(xₙ·conj(xₙ₋₁)) − slope), первое — 0. Сумма по 8 приращениям символа (у GMSK после 16 отсчётов гауссовой задержки) идёт в `m_value` (36 бит), решение `m_bit` = сумма ≥ 0.

Проход данных берёт по два отсчёта за такт: `cpm_samples` хранит кадр в восьми банках (индекс mod 8), и пять отводов двух соседних кубических интерполяций всегда попадают в разные банки. Два CORDIC считают приращения пар, символ занимает четыре такта. С одним отсчётом за такт к захвату каждого кадра добавлялось отставание, и при непрерывном потоке вход останавливался (тестбенч требует не больше 32 тактов ожидания). Захват читает по одному отсчёту (полоса 0).

| Узел | Формат |
| --- | --- |
| Вход | Q3.15, кадр 8N…8N+96 отсчётов с TLAST, N = 192…2048 |
| Конфигурация | 192 бита преамбулы и N, как у `bpsk_rx` |
| Задержка | 32 бита, 16 дробных (в интерполятор идут 8) |
| Частота | 32 бита, оборотов·2³² на отсчёт |
| Выход | `m_value` 36 бит (сумма приращений символа), `m_bit`, `m_last`; `acquisition_delay/frequency` с импульсом `acquisition_valid` |

## Когерентный GMSK (`GMSK=1`)

По решению пользователя (2026-10-06) GMSK принимается когерентно, как в оригинале Simulink (приёмник Менгали). Переносимая модель `modem_core` и её Octave/SV-варианты остаются с дискриминатором. Вещественный эталон когерентного приёма — `common/python/gmsk_coherent.py`, целочисленный — `cpm_fixed.receive_coherent`, RTL — `cpm_coherent.sv` внутри `cpm_rx`.

При h = 1/2 сигнал GMSK ≈ Σ αₖ·C0(t − kT) (главный импульс Лорана), αₖ = j·aₖ·αₖ₋₁. C0 строится из фазового импульса передатчика на сетке отсчётов (48 отводов, Q15), остаток приближения — около 6 % по амплитуде.

1. **Захват** — тот же, что у MSK, плюс начальная фаза: свободный член МНК по фазам блоков, divide(Σp_j, 8) − round(slope·1023, 1). Вещественная подгонка по сетке задержек теряет целые кадры ниже ~4 дБ на отсчёт, поэтому и вещественный эталон берёт этот захват.
2. **Согласованный фильтр**: zₖ = round(Σ x[8k+m]·C0[m], 20) по позициям n + задержка − 1/2 (оценка задержки по дискриминатору смещена на полотсчёта). В RTL — шесть скользящих накопителей (по одному на символ в работе), по два отсчёта за такт, 24 произведения.
3. **Петля фазы на символ**:
   - θₖ = фаза + частота·(8k + 23.5) + фаза петли;
   - поворот `bpsk_rotate`, затем поворот на ось умножением на (−j)^(k+1);
   - решение βₖ = знак действительной части;
   - ошибка — angle(r·цель) через CORDIC, ограничена 0.5 рад; на преамбуле цель известна.
   
   Коэффициенты 0.04 и 0.0002 (Q15: 1311 и 7). Поправка применяется через 10 символов: в RTL от выхода фильтра до готовой ошибки около 38 тактов при символе за 4 такта.
4. **Данные**: aₖ = βₖ·βₖ₋₁ (β₋₁ = +1). `m_value` — мягкое значение после поворота на ось (19 бит, расширено до 36).

После поворота на ось вклад соседних символов C0 (ρ₁ = 0.51) уходит в мнимую часть, на решение влияет только ρ₂ = 0.056. Поиск Витерби по β давал те же числа ошибок, поэтому приёмник линейный.

## Сравнение с вещественной моделью

MSK (дискриминатор), 4 кадра по 1536 символов на ОСШ, задержки 0…1.11 отсчёта:

| Модель | 0 дБ | 3 дБ | 6 дБ | 9 дБ |
| --- | --- | --- | --- | --- |
| MSK, целочисленный | 594 | 112 | 4 | 0 |
| MSK, вещественный | 1209 | 147 | 4 | 0 |

GMSK, 8 кадров по 1536 символов (ОСШ на отсчёт; Es/N0 на 9 дБ выше):

| Приёмник | −6 дБ | −4 дБ | −2 дБ | 0 дБ | 3 дБ |
| --- | --- | --- | --- | --- | --- |
| когерентный, целочисленный (RTL) | 1367 | 784 | 70 | 4 | 0 |
| когерентный, вещественный эталон | 1317 | 810 | 70 | 4 | 0 |
| дискриминатор, целочисленный | 4377 | 3994 | 3227 | 2212 | 1179 |

Когерентный приём выигрывает у дискриминатора около 6–8 дБ. На сценариях `modem_checks.py` (усиление 0.65/0.2/0.8/1.3, частота до 5·10⁻⁴, задержка до 7.25) ошибок нет у обоих приёмников; при −8 дБ ошибок больше 20, как требует проверка чувствительности.

- трёхступенчатое накопление корреляции;
- смещение запроса в проходе данных, посчитанное один раз на кадр.

## Сверка передатчика MSK с оригиналом Simulink

`python3 tools/check_msk_matlab_rtl.py` (тестбенч `rtl/tb/cpm_tx_dump_tb.sv`) берёт 511 бит скремблера и 16 352 отсчёта выхода оригинала из `build/matlab_msk_reference` (их готовит `tools/check_matlab_msk.py`, 32 отсчёта на символ).
- При 8 отсчётах на символ отсчёт t фазовой траектории MSK — это отсчёт 4t + 3 захвата: та же фаза после 4(t + 1) шагов. Вещественная модель при sps = 8 совпадает с прореженным захватом до 10⁻¹⁴.
- RTL `cpm_tx` (`GMSK=0`) выдаёт 4088 отсчётов. Они совпадают с `cpm_fixed.transmit` бит в бит и с захватом — до 2.05·10⁻⁵, это округление таблицы cos до Q15.
- Проверено при обеих полярностях сброса, со случайным `m_ready` и без.
- Контроль чувствительности: сдвиг на один отсчёт даёт расхождение больше 10⁻².
