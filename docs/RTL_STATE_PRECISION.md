# Notch, Kalman и FSK: общие квантованные данные

`tools/state_precision.py` содержит 15 случаев. Это точность Python моделей; новые RTL измерения качества не заявляются.

Notch float использует общие Q15 входы и загруженные Q16 b1/a1/a2, собственные нулевые начальные состояния и полную causal recurrence. Четыре обычных случая дают SQNR 83.09–86.83 dB и RMS 1.255–1.538×10⁻⁵ нормализованных единиц амплитуды. Выходной clipping stress даёт 782 события; port-valid нестабильные коэффициенты отдельно дают 248 state/output events обоих знаков и не признаются стабильным качественным профилем.

Kalman float самостоятельно обновляет covariance/value по общим Q24 Q/R/P0, не получает fixed gains. Три ненулевых профиля дают SQNR 90.07–90.80 dB и RMS 1.235–1.370×10⁻⁵; gain 0 контроль совпадает точно, без обещания слежения за сигналом. Legal rail stress не даёт clamps, согласованно с convex update; RMS 4.231×10⁻⁵. Tracking error относительно известного сигнала измеряется отдельно.

FSK fixed LUT/rounding сравнивается с аналитическими phasors на тех же uint32 phase increments и общем один раз квантованном waveform. Reference не получает transmitted labels; они используются только для scoring. Четыре fixed-model/float решения совпадают: SER 0/0/0/0.25. Случай−12 dB содержит 1368 input clamps, которые отделены от реализованной энергии AWGN. Максимальный correlator RMS 0.00017074 нормализованных единиц амплитуды. Для блока 40 отсчётов нормировка равна 64, как в фиксированном correlator, и объявлена в эталоне.

Восемь тестов проверяют независимость/causality, формулы recurrences, полные счётчики операций, границы интервалов, воспроизводимость шума, faults в метаданных и завершённый source-bound PASS/FAIL. В отчёте сохранены реальные решения и комплексные корреляции обоих приёмников. Проверка пересчитывает argmax и SER относительно исходных символов; согласованные подмены счётчиков, решений и корреляций отклоняются.

Смена рабочих разрядностей и новая область устойчивости не заявляются.
