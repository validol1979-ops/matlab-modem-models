# QPSK: квадратурный модем и восстановление несущей петлёй Costas

Цепочка: биты → разделение I/Q → формирующие FIR → квадратурная модуляция → гауссов шум → смешение с локальной несущей → НЧ FIR → решение по знаку I/Q → объединение битов. Команда `run_demo` воспроизводит вычислительные сценарии `qpsk_modem_basic.m` и `qpsk_modem_costas.m` в арифметике double.

Параметры оригинальных скриптов: несущая 50 кГц, поток бит 10 кбит/с, дискретизация 1 МГц, **100 отсчётов на бит и 200 на QPSK-символ**. I/Q принимают значения ±1 до фильтрации: четыре сочетания `(±1, ±1)`; нормировка на единичную энергию не применяется. Формирующий фильтр порядка 40: `firrcos`, тип `sqrt`, rolloff 0,25, Kaiser с параметром 0,5. НЧ фильтр порядка 30: `fir1`, срез 16 кГц, прямоугольное окно. Указанный в авторском README rolloff 0,5 расходится с кодом `rcosfilter.m`; демо следует коду — 0,25.

В basic несущая приёмника совпадает с передающей; фильтр фазового детектора не управляет генератором. В Costas локальная частота 50,1 кГц, начальная расстройка +100 Гц, детектор `sign(I)*Q-sign(Q)*I`, коэффициенты петли `C1=1/16`, `C2=1/128`. Отдельного устройства символьной синхронизации нет: решения берутся в известных точках `100:200:end`. Gardner из описания FPGA-проекта в этих MATLAB-скриптах отсутствует. АРУ и эквалайзера нет.

## Запуск

Перейдите в эту папку в MATLAB:

```matlab
run_demo
run_demo(1000)
```

`N` — чётное число бит для опытов с расстройкой, не меньше 40; по умолчанию 240. Basic всегда передаёт исходные фиксированные 40 бит. Допустим вызов `r = run_demo(N)` для доступа к сигналам и решениям.

Проверено в MATLAB R2020b (9.9.0.1467703) и GNU Octave 8.4.0 с `gnuplot`. **Для `run_demo` нужен только MATLAB**, без Simulink и дополнительных toolbox: коэффициенты FIR уже вычислены и сохранены в `demo_fir_coefficients.m`, шум создаётся через `randn`. Это относится к новому запуску; оригинальные скрипты обращаются к `awgn`, `firrcos`, `dfilt` и настройкам фиксированной точки и имеют дополнительные зависимости.

Данные не записываются. Состояние генератора случайных чисел восстанавливается после опыта. MATLAB и Octave могут выдавать разные случайные последовательности при одинаковом seed.

## Что смотреть

- `QPSK: decisions and sampled I/Q`: переданные и принятые биты, а также отсчёты I/Q в центрах символов для basic, расстройки без обратной связи и Costas. При расстройке без коррекции точки вращаются; с петлёй группируются около четырёх положений. Переходные отсчёты включены.
- `QPSK: Costas phase detector and loop filter`: выход детектора, управляющая фаза относительно линейного набега от 100 Гц и остаточная фаза по модулю π/2. Управляющая фаза при компенсации частотной ошибки растёт; её не следует ожидать около нуля.
- `QPSK: waveform and receiver I/Q`: фрагмент полосового сигнала до/после шума и выходы приёмных FIR.

Командное окно показывает число ошибочных битов, включая запуск фильтров. В проверке MATLAB R2020b при `N=240`: basic — 0/40, расстройка без обратной связи — 115/240, Costas — 0/240. Это один учебный опыт, не BER-кривая. Фазовая неоднозначность QPSK π/2 не разрешается отдельным декодером. Шум соответствует исходному `awgn(tx,20)` с принятой по умолчанию мощностью сигнала 0 dBW: дисперсия 0,01; это не SNR 20 дБ относительно измеренной мощности `tx`.

## Изменения относительно оригинала

Оригинальные четыре `.m` сохранены без изменений. `run_demo.m` — адаптация их вычислительной части, а не прямой запуск скриптов с очисткой workspace и экспортом `dataI.txt`/`dataQ.txt`.

- Фильтры `dfilt` с фиксированной точкой заменены на double FIR с исходными неквантованными коэффициентами; **побитовая эквивалентность фиксированной арифметике не заявляется**. Коэффициенты получены в R2020b по выражениям, приведённым в `demo_fir_coefficients.m`; параметры и усиление не перенормированы.
- В Costas сохраняется состояние FIR между отсчётами вместо повторной фильтрации всего буфера; сохранены детектор, знак обратной связи и уравнение петли.
- Добавлен опыт с теми же битами и шумом при +100 Гц без обратной связи, графики созвездия и остаточной фазы. Сохранены известные точки решений без компенсации задержки фильтров.
- Вместо исходных многочисленных окон открываются три; TXT не экспортируются.

Копии исходников в рабочих каталогах `qpsk_script_basic/original` и `qpsk_script_costas/original` идентичны пофайлово; это один комплект из двух разных сценариев, а не два идентичных скрипта basic и Costas. `migration.json` и `matlab/verification.json` для этого комплекта отсутствуют. Параметры переносимых аналогов из `config.json` (8 отсчётов/символ и тренировочная преамбула) к оригинальным скриптам не относятся.
