# QPSK: быстрая тактовая и фазовая синхронизация без обратной связи

Модель Simulink демонстрирует QPSK с прямой оценкой тактовой фазы, фазы несущей и усиления. Передатчик: скремблер → дифференциальное кодирование → QPSK → повышение частоты в 8 раз → RRC. Канал: задержка, фазовая/частотная расстройка и AWGN. Приёмник: RRC → `symbol_sync` (модуль сигнала, фильтрация и выделение тактов) → `one_sps_clock_domain` с фазовой коррекцией, развёрткой фазы и `gain_control` → декодирование.

Параметры: 8 отсчётов на символ; M = 4, Ph = 0, передающие точки {1, i, −1, −i}; передающий и приёмный RRC порядка 32 с коэффициентом скругления 1. В этой модели нет дробного интерполятора Фарроу и адаптивного эквалайзера.

## Запуск

Перейдите в эту папку из MATLAB:

```matlab
run_demo
% С явным временем окончания:
run_demo(2048)
```

N в `run_demo(N)` — время окончания в единицах модельного времени, а не число символов. Без аргумента используется `16384`.

Проверено в MATLAB R2020b: исходный отчёт подтверждает симуляцию и точный повтор до времени 2048. Полная корректность приёмника не установлена.

Нужны MATLAB, Simulink, Communications Toolbox (PSK, канал, расстройка, скремблер и Scatter Plot), DSP System Toolbox (RRC, задержки, буферы и изменение частоты), Signal Processing Toolbox (`firrcos` в RRC-библиотеке `dspddes3`).

## Что смотреть

- Автоматически открывается `Discrete-Time Scatter Plot Scope1`: символьные отсчёты после коррекции; смотрите четыре группы QPSK.
- Вручную: `Scope2` — выделенный тактовый сигнал `symbol_sync`; `Scope1` — оценка усиления из `one_sps_clock_domain`.
- `Scope4` показывает I/Q скорректированного сигнала; `Scope5` — декодированные метки; `signal_power(Watts)` — оценку мощности. Сходимость можно оценивать визуально; численного критерия захвата в этих окнах нет.
