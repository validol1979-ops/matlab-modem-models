# 8-PSK: быстрая прямая синхронизация без обучающей последовательности

Модель демонстрирует прямое выделение символьного такта и фазы 8-PSK без использования известных приёмнику символов (NDA).

Цепочка: скремблирование и дифференциальное кодирование → 8-PSK и RRC-фильтр → фазовый/частотный сдвиг и AWGN → согласованный RRC-фильтр → `symbol_sync` по модулю сигнала с FIR/CIC и Hit Crossing → фазовая оценка по восьмой гармонике, CIC-усреднение и развёртка → фазовые решения, дифференциальное декодирование, Gray-декодер и дескремблер. В отличие от варианта с обратной связью 2009 года, здесь нет отдельной петли Gardner и узла АРУ.

Параметры: 8 отсчётов на символ, `M = 8`, `Ph = 0`; RRC-фильтры порядка 32, скругление 1; `Eb/No = 13 дБ`. Восемь точек созвездия расположены равномерно по окружности.

## Запуск

В MATLAB перейдите в папку этой модели, где находятся `.mdl` и `run_demo.m`:

```matlab
run_demo          % длительность по умолчанию из run_demo.m
run_demo(2048)    % явная длительность в единицах модельного времени
```

Функция принимает `run_demo(N)`, где `N` — конечное модельное время, а не число символов. Вызов без аргумента использует длительность, заданную в `run_demo.m`.

Проверено в MATLAB R2020b: симуляция до модельного времени 2048 и точное повторение записанных сигналов после перезапуска — `PASS` по `matlab/verification.json` исходного проекта. Полная эквивалентность исторической версии и функциональная корректность всего приёмника не установлены.

Нужны MATLAB и следующие продукты:

- Simulink — схема и её выполнение.
- Communications Toolbox — M-PSK модулятор, AWGN, скремблер/дескремблер и диаграмма рассеяния.
- DSP System Toolbox — RRC-фильтры, Buffer, Upsample/Downsample и задержки.
- Signal Processing Toolbox — обязательная зависимость DSP System Toolbox и Communications Toolbox в [R2020b по требованиям MathWorks](https://www.mathworks.com/content/dam/mathworks/mathworks-dot-com/support/sysreq/files/2020b-product-availability.pdf).

## Что смотреть

Автоматически открывается `Discrete-Time Scatter Plot Scope1` с выходом фазовой синхронизации: по восьми группам отсчётов оценивают качество фазовой оценки. Внутри передатчика `Modulator/Data_Source1/Scope` сохранён открытым и подключён к `Scrambler1`.

Вручную доступны `Scope4` с I/Q и `Scope5` с восстановленными данными. Графика ошибки замкнутой тактовой петли здесь нет. Название «быстрая» взято из оригинала; измеренное время захвата имеющейся проверкой не установлено.
