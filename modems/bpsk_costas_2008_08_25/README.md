# BPSK: восстановление тактовой частоты и фазы петлёй Костаса

Модель передаёт дифференциально кодированные двоичные данные через канал с шумом и восстанавливает их когерентным приёмником.

Цепочка: скремблер → дифференциальный кодер → BPSK и RRC-фильтр → фазовый/частотный сдвиг, дробная задержка и AWGN → согласованный RRC-фильтр, интерполятор Фарроу → тактовая петля Gardner, фазовая петля Костаса и АРУ → решения и декодирование.

Параметры: 8 отсчётов на символ; таблица передатчика `[0.5+0.5i, -0.5-0.5i]`. RRC-фильтры имеют порядок 32 и коэффициент скругления 1. В канале выбран `Eb/No = 8 дБ`. Приёмник содержит области обработки с 2 и 1 отсчётом на символ.

## Запуск

В MATLAB перейдите в папку этой модели, где находятся `.mdl` и `run_demo.m`:

```matlab
run_demo          % длительность по умолчанию из run_demo.m
run_demo(2048)    % явная длительность в единицах модельного времени
```

Функция принимает `run_demo(N)`, где `N` — конечное модельное время, а не число символов. Вызов без аргумента использует длительность, заданную в `run_demo.m`.

Проверено в MATLAB R2020b: симуляция до модельного времени 2048 и точное повторение записанных сигналов после перезапуска — `PASS` по `matlab/verification.json` исходного проекта. Полная эквивалентность исторической версии и функциональная корректность всего приёмника не установлены.

Нужны MATLAB и следующие продукты:

- Simulink — схема и её выполнение.
- Communications Toolbox — AWGN, скремблер/дескремблер, фазовый/частотный сдвиг и диаграмма рассеяния.
- DSP System Toolbox — RRC-фильтры, Buffer, Upsample/Downsample и задержки.
- Signal Processing Toolbox — обязательная зависимость DSP System Toolbox и Communications Toolbox в [R2020b по требованиям MathWorks](https://www.mathworks.com/content/dam/mathworks/mathworks-dot-com/support/sysreq/files/2020b-product-availability.pdf).

## Что смотреть

Автоматически открывается `Discrete-Time Scatter Plot Scope1`: отсчёты выхода `scatter` после восстановления синхронизации; по двум группам точек оценивают качество приёма BPSK.

Остальные окна открываются двойным щелчком: `Scope1` показывает строб и дробную задержку `mu` тактового NCO; `Scope4` — I/Q выходных отсчётов; `Scope5` — восстановленные данные. Это наблюдение сигналов, а не автоматическая проверка BER.
